# Saksham's Studio — portfolio website

Static site for GitHub Pages. No build step.

- `index.html` — the page (design + text)
- `site-config.js` — **edit this** for email, YouTube links, rates
- `assets/` — logo, emblem, favicon

The inquiry form uses FormSubmit (free). The first inquiry sends an activation
email to the address in `site-config.js` — click "Activate" once.
